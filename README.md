# KingdomFlow Version Policy

This repository is a public distribution mirror for the **signed KingdomFlow version-policy JSON only**.

## Contents

- `policy.json` — the public Ed25519-signed policy envelope served primarily by the KingdomFlow Cloudflare Pages endpoint.

## Security rules

- Keep this repository limited to the signed public policy document and non-sensitive documentation.
- Never upload application source code, executables, release archives, backups, user data, Keygen credentials, environment files, or private signing keys.
- The Ed25519 private signing key remains on the trusted release machine. The signature in `policy.json` is public verification data.
- Clients verify the signature and policy contents locally. Editing the JSON invalidates its signature.
- Update `policy.json` only with the exact signed envelope generated by the trusted release workflow. Use the same bytes for the Cloudflare policy setting and this GitHub mirror.

The expected customer download URL is:

`https://raw.githubusercontent.com/develp4fun/KingdomFlow-Version-Policy/main/policy.json`

The policy file will be added when a valid signed release policy has been generated from an approved release executable.
